# notemouse
notemouse a mouse-less notepad, fully operatable through just your keyboard. no mouse needed!

### commands
| keyboard shortcut | result |
| :---------------: | -----: |
| CTRL+Q | show or hide the commands panel |
| CTRL+S | download as .md file |
| CTRL+A | save to localStorage |
| CTRL+Z | undo text you just typed |
| CTRL+F | find a portion of text |
| CTRL+V | paste text from clipboard |
| CTRL+C | copy highlighted text to clipboard |
| SHIFT+ARROWS | highlight a portion of text |
| ARROWS | scroll through text |
| CTRL+Y | switch to dark or light mode |
